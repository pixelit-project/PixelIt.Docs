## Supported hardware

Install PixelIt on a supported prebuilt clock or build a DIY display. Optional sensors, buttons and a DFPlayer Mini extend its capabilities.

<a id="prebuild-hardware"></a>

### Prebuilt Hardware

## Getting started

- Start with the [hardware](hardware.html) and check out the [parts list](hardware.html#diy-components-list).
- Then you can flash the [firmware](firmware.html) and configure the matrix in the [webinterface](webinterface.html).
- Finally, send screens through the [API](api.html) or use [Node-RED](nodered.html) (recommended) or [ioBroker](iobroker.html) to create and send your own screens to your PixelIt.
