Install PixelIt

Choose your firmware and board, then connect via USB.

The stable release is recommended for everyday use.

USB installation is unavailable in this browser. Try desktop Chrome or Edge. Open this installer over HTTPS to connect your device. Use a USB cable that supports data.

Flash a local firmware file

Install an older version or your own build from your computer. Download older releases ↗

Choose the firmware for your exact board. For ESP32, use a file ending in .full-upgrade.bin; for ESP8266, use the matching .bin file. ESP32 OTA application files cannot be installed here.

The connected chip is detected automatically. The filename determines the supported image type; it does not verify the board or file contents. Your file stays on your computer and is not uploaded.
